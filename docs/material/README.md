# Material de referencia

Esta carpeta guarda documentos de consulta que **no forman parte del código**
del sistema.

## `Libro PDF Señario LSA Volumen 1.pdf`

- Es un PDF de ~26 MB con vocabulario de Lengua de Señas Argentina.
- **No se versiona**: está excluido en `.gitignore` por tamaño y por derechos
  de autor (`docs/material/*.pdf`).
- Queda solo en la copia local del proyecto.

Si el repositorio es **privado** y tenés permiso para distribuirlo:

```powershell
git add -f "docs/material/Libro PDF Señario LSA Volumen 1.pdf"
git commit -m "docs: agregar material de referencia LSA"
```

Para un repositorio público, lo recomendable es no subirlo y enlazar la fuente
original en su lugar.

El resto de la documentación del proyecto está en
[`../README.md`](../README.md).
